Proje Hakkında

Bu proje, restoran ve kafelerde sipariş süreçlerini dijitalleştirmek amacıyla geliştirilmiş QR kod tabanlı bir menü ve sipariş sistemidir.
Müşteriler masalarına özel QR kodu okutarak menüye erişebilir ve doğrudan sipariş oluşturabilir.

 Özellikler
QR kod ile menüye erişim
Online sipariş oluşturma
Yönetim paneli üzerinden sipariş takibi
Sipariş onaylama ve servis yönetimi
Entegre ödeme sistemi
Gerçek zamanlı sipariş iletimi
 Sistem Nasıl Çalışır?
Müşteri QR kodu okutur
Menü arayüzü açılır
Sipariş oluşturulur
Sipariş işletme paneline iletilir
Çalışan siparişi onaylar ve servis süreci başlar
 Kullanılan Teknolojiler
Backend: Flask
Veritabanı: SQLite
Frontend: HTML, CSS, JavaScript
API: RESTful servisler
 Katkım
Sipariş yönetim sistemi geliştirme
Backend ve API geliştirme
Veritabanı tasarımı
Gerçek zamanlı sipariş akışı
 Kurulum
git clone https://github.com/alzimar104/menu_system1.git
cd menu_system1
pip install -r requirements.txt
python app.py

 Amaç

Bu proje, geleneksel sipariş yöntemlerini dijital ortama taşıyarak hem müşteri deneyimini iyileştirmeyi hem de işletme süreçlerini daha verimli hale getirmeyi hedeflemektedir.
